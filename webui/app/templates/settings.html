Settings – HandBrake TSD Helper

Encoding Settings

Control how many CPU threads HandBrake can use during encoding. Setting this higher lets the encoder use more of your CPU (faster encodes, but more system load).

Tip:
- 0 or blank = let HandBrake decide (auto).
- A good starting point is the number of physical cores on the machine running this container.

Upload HandBrake Preset (.json)

Upload your own HandBrake preset JSON files into the presets folder used by this app. After uploading, they will appear in the preset dropdowns on the Jobs page.
