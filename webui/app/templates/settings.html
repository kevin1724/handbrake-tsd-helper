Encoding Settings

Control how many CPU threads HandBrake can use during encoding.

This only affects Size Wizard ETA estimates. It does not change HandBrake quality or presets.

Tips:
- 0 threads = let HandBrake decide automatically
- Pick the CPU closest to the machine running this container
- Small OptiPlex / Tiny PCs may run slightly slower due to thermals
