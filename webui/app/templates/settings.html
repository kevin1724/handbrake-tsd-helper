    Linked Nodes

    Pair worker nodes, map controller paths to worker paths, and dispatch jobs to local or remote queues.

    Node linking tutorial

    1. Create a worker code

    1. Open Settings on the worker node.
    2. Click Generate pairing code.
    3. Leave the worker running while you pair it from the controller.

    2. Pair from the controller

    1. Enter the worker URL, such as http://192.168.1.50:8081.
    2. Paste the pairing code and add a friendly name.
    3. Click Pair worker, then Refresh linked nodes.

    3. Choose the media mode

    Auto local then remote tries path mapping first, then uses remote transfer if no mapping matches.

    Local mounted media mode is best when the worker can see the media folders directly.

    /media/Movies => /mnt/media/Movies /media/Shows => /storage/Shows

    Remote transfer mode downloads a temporary copy to the worker temp folder, encodes it, uploads the finished -TSD file, and the controller verifies it before replacing anything.

    4. Send jobs

    1. Use Beta to select Local queue, Best worker, or a specific worker.
    2. The controller sends the selected preset JSON to the worker with each node job.
    3. Pairing codes are one-use and expire quickly; node secrets and transfer links are not shown in logs.
