Built-in guide

How Autopilot works

Recommended: map folders, approve two good preview samples, use Observe for at least one scan, then switch to Manage.

1. Map your library

Autopilot only looks inside the Movies and Shows folders you explicitly map in Library Settings. Refresh the Library after changing folders.

2. Teach visual quality

Select Create preview. A short section is encoded and shown beside the original. Approve it if you would happily watch a whole movie at that quality. Reject it and choose why if you would not.

3. Observe decisions

Observe mode never queues anything. Run a cycle and read why each file is eligible, waiting, or skipped. Adjust minimum size, savings, and schedule until the choices feel right.

4. Enable Manage

Manage can add only the configured number of jobs and only while capacity is available. It still waits for files to stop changing and will not remove a source until encode verification succeeds.

5. Keep teaching after playback

Completed learned jobs appear in the feedback section. If the movie looked good, approve it. If it looked bad, choose whether quality, size, playback, audio, or subtitles were the problem. This feedback changes later recommendations for similar sources.

What training changes

  • Preferred quality and compression tradeoff for similar resolution and HDR sources.
  • Codec, encoder family, and target-size choices.
  • Confidence in whether a candidate is safe to choose automatically.

What it never bypasses

  • Mapped-folder boundaries and file stability.
  • Queue capacity and your operating schedule.
  • Existing output-size checks, encode validation, and source protection.
