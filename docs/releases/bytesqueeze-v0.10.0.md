# ByteSqueeze 0.10.0

ByteSqueeze 0.10.0 brings the Size Wizard and preference-learning workflow to the Android app while making everyday screens calmer by default.

- Library movies open directly in a native Size Wizard.
- Every show episode has its own Size Wizard action and independent plan.
- The Wizard starts from learned preferences for similar movie/show, HDR/SDR, and resolution context.
- Queueing a Wizard plan records the exact approved codec, encoder, bit depth, quality, speed, size ratio, audio, and subtitle choices for future Smart recommendations.
- Source frame rate remains locked when a mobile Wizard plan is customized.
- Wizard jobs can stay on the main controller or use the next available node.
- Primary screens hide duplicate helper cards, filters, refresh controls, and technical counters by default.
- Interface & UI settings can restore secondary controls or enable Stats for nerds, including paths, addresses, bitrates, events, and low-level capacity details.

This mobile release pairs with controller 3.20.0 and worker 2.7.1.
